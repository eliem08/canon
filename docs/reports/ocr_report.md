# OCR benchmark (synthetic contracts rendered as scans)

Generated by `uv run python scripts/ocr_benchmark.py`. Each of the synthetic contracts is rendered as a 2-page image-only PDF (DejaVu Sans, about 200 dpi; `noise` = share of pixels flipped at random), read back with tesseract (fra+ara+eng), and parsed. A field counts as correct when the value read from the scan equals the value read from the original text; *wrong* means a different value was read (the rest were refused or not found).

These are clean renders of a known font. Real scans (skew, stamps, signatures, fax artefacts, handwriting) will be worse, so measure on the client's files.
