# Testing report

*Part of the product document set (`docs/product/`). Code claims cite repository paths. Written by the agent that built most of the code: a self-assessment, not independent review. Updated 2026-10-30.*

All results below were produced by commands run on 2026-10-30 in the development container (Linux, Python 3.12).

`resolve` with `--network none`.

## What the suite covers

| Kind | Examples |
|---|---|
| Unit | Parsers with adversarial fixtures (`tests/fixtures/parsing_cases.json`), name normalisation, scoring, contract terms |
| Integration | Ingest → resolve → score on the synthetic export; audit and deliverables; `pilot` end to end |
| API (MCP) | Every tool for every caller; stdio client; HTTP with tokens; `/health` |
| Auth / authorization | 401s, token identity, revocation, OIDC verification, per-caller leak checks |
| End-to-end UI | Review page in Chromium: answer a merge, refused bad date, correction, download, rerun applies both |
| Failure handling | Refused values, unreadable documents, purge refusals, pull errors |
| Regression | Synthetic dataset asserted to match the committed copy; benchmark reports regenerated by scripts |
| Performance | `scripts/scale_benchmark.py` (results below) |
